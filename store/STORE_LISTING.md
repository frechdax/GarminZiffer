# Blush Dial — Connect IQ Store Listing

## App name
Blush Dial

## App type
Watch Face

## Supported devices
- Garmin Venu 3
- Garmin Venu 3S
- Garmin vívoactive 5

## English

### Short description
Elegant AMOLED watch face with blush and lavender accents, time, date, steps and battery.

### Full description
Blush Dial is a clean, feminine watch face designed for AMOLED Garmin watches.

The design combines a dark plum background with blush and lavender accents for a soft, modern look that remains easy to read at a glance.

Features:
- Large digital time
- Automatic 12/24-hour format based on device settings
- Date
- Daily step count
- Battery percentage
- Reduced low-power / always-on presentation
- Layout scaled for Venu 3, Venu 3S and vívoactive 5

Blush Dial does not require an account, internet connection or additional permissions.

## Deutsch

### Kurzbeschreibung
Elegantes AMOLED-Zifferblatt mit Rosé- und Lavendel-Akzenten, Uhrzeit, Datum, Schritten und Akku.

### Vollständige Beschreibung
Blush Dial ist ein klares, feminines Zifferblatt für AMOLED-Garmin-Uhren.

Das Design kombiniert einen dunklen Pflaumen-Hintergrund mit Rosé- und Lavendel-Akzenten. Dadurch bleibt das Zifferblatt modern, ruhig und auf einen Blick gut lesbar.

Funktionen:
- Große digitale Uhrzeit
- Automatischer 12-/24-Stunden-Modus entsprechend der Geräteeinstellung
- Datum
- Tägliche Schrittzahl
- Akkustand in Prozent
- Reduzierte Darstellung im Energiespar-/Always-on-Modus
- Angepasst für Venu 3, Venu 3S und vívoactive 5

Blush Dial benötigt weder ein Benutzerkonto noch eine Internetverbindung oder zusätzliche Berechtigungen.

## Privacy / data use
- No account
- No network access
- No location access
- No user data is transmitted
- No analytics
- No advertising
- No additional Connect IQ permissions requested
